# Real Block Breaker

[English](README.md) | **日本語**

鋼の筐体の中を転がる銀色の玉で、制限時間内にできるだけ多くのブロックを砕くブラウザゲームです。
HTML / CSS / JavaScript (Canvas 2D + Web Audio API) のみで書かれており、ビルドや依存パッケージは不要です。

## 遊び方

- 画面の下は壁になっていて、玉は落ちません。ミスの概念はなく、**90 秒の制限時間**内でスコアを競います。
- 下の壁にある **クロームのディフレクター** を左右に動かし、玉を当てると **当たった位置に応じた角度** で打ち出されます。狙った方向へ玉を誘導しましょう。
- ブロックを連続で砕くとコンボが伸び、4 コンボごとにスコア倍率が上がります（最大 x8）。ディフレクター以外の壁に当たるとコンボが途切れます。
- 砕けたブロックは **しばらくすると同じ場所に再生** します。再生までの時間は耐久力に比例します（耐久力 × 6 秒）。再生中の空きソケットにはゲージが表示されます。
- ブロック群の総数ぶん砕くと **ウェーブクリア** です（再生したブロックを砕いた分も数えます。WAVE 欄のバーが進捗）。ボーナス得点と **時間延長 (+10 秒)**、新しいブロック群が現れ、玉が 1 個追加されます（最大 3 個）。ウェーブが進むほどブロックは硬く、玉は速くなります。
- WAVE 3 からは **剛鉄ブロック**（リベット付きのステンレスの塊）が混ざります。絶対に砕けず、玉をはじき返すだけで、クリアの必要数にも数えません（PIERCE 中でも貫通できません）。数は 2 ウェーブごとに 1 つ増え、最大 6 か所です。配置は「盤面の連結成分を増やさない」（＝玉が入り込めない袋小路を作らない）場所だけから選ばれるので、砕けないブロックに囲まれてクリア不能になることはありません。
- ブロックを砕くとたまに **アイテム** が落ちてきます。ディフレクターで受け止めると効果が一定時間続き、ディフレクター以外の壁に落ちると消えます。
  - 基本排出率は **20%**。抽選が9回連続で外れると次は必ず排出されます。排出間隔は最低1.25秒、落下中は最大3個で、この制限中の破壊は抽選・連続外れの対象外です。4種類は同じ確率で選ばれます。
  - **SPEED**（8 秒）: 玉の速度が大きく上がります。
  - **BLAST**（10 秒）: ブロックが砕けるたびに衝撃波が広がり、上下左右に隣接するブロックにも 1 ヒットずつ与えます（衝撃波で砕けたブロックは連鎖しません）。
  - **x2**（10 秒）: 玉の数が 2 倍になります（効果が切れると増えた分は消えます）。
  - **PIERCE**（8 秒）: 玉がブロックを貫通し（通過したブロックに 1 ヒットずつ）、壁に到達したときだけ跳ね返ります。
- ベストスコアはブラウザの `localStorage` に保存されます。

## 実行方法

`index.html` をブラウザで直接開くだけで遊べます。

ローカルサーバーで動かす場合の例:

```bash
python3 -m http.server 8765
```

その後 http://localhost:8765/ を開いてください。

## Cloudflareへのデプロイ

Node.js 22以降とCloudflareアカウントが必要です。

```bash
npx wrangler@4.131.1 login
npx wrangler@4.131.1 deploy
```

`wrangler.jsonc` で `easy-block-breaker` Workerを設定しています。デプロイ時に `scripts/prepare-deploy.cjs` がゲーム本体とライセンスだけを `dist/` にコピーし、`workers.dev` 上に静的ファイルとして公開します。

## ファイル構成

```

js/core.js        共通設定とユーティリティ
js/audio.js       効果音
js/renderer.js    Canvas 描画とテクスチャ
js/game.js        ゲーム状態・ルール・入力・ループ
```
