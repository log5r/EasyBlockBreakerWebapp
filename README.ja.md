# Real Block Breaker

[English](README.md) | **日本語**

鋼の筐体の中を転がる銀色の玉で、制限時間内にできるだけ多くのブロックを砕くブラウザゲームです。
HTML / CSS / JavaScript (Canvas 2D + Web Audio API) のみで書かれており、ビルドや依存パッケージは不要です。

## 遊び方

- 画面の下は壁になっていて、玉は落ちません。ミスの概念はなく、**90 秒の制限時間**内でスコアを競います。
- 下の壁にある **クロームのディフレクター** を左右に動かし、玉を当てると **当たった位置に応じた角度** で打ち出されます。狙った方向へ玉を誘導しましょう。
- ブロックを連続で砕くとコンボが伸び、4 コンボごとにスコア倍率が上がります（最大 x8）。ディフレクター以外の壁に当たるとコンボが途切れます。
- 全ブロックを消すとボーナス得点と **時間延長 (+10 秒)**、新しいブロック群が現れ、玉が 1 個追加されます（最大 3 個）。ウェーブが進むほどブロックは硬く、玉は速くなります。
- ブロックを砕くとたまに **アイテム** が落ちてきます。ディフレクターで受け止めると効果が一定時間続き、ディフレクター以外の壁に落ちると消えます。
  - **SPEED**（8 秒）: 玉の速度が大きく上がります。
  - **BIG**（10 秒）: 玉のサイズが大きくなります。
  - **x2**（10 秒）: 玉の数が 2 倍になります（効果が切れると増えた分は消えます）。
- ベストスコアはブラウザの `localStorage` に保存されます。

### 操作

| 操作 | キー |
| --- | --- |
| ディフレクター移動 | マウス / タッチ、または <kbd>←</kbd> <kbd>→</kbd> / <kbd>A</kbd> <kbd>D</kbd> |
| スタート / リトライ | <kbd>Space</kbd> / <kbd>Enter</kbd> または画面のボタン |
| ミュート切替 | <kbd>M</kbd> または右上のボタン |

## 実行方法

`index.html` をブラウザで直接開くだけで遊べます。

ローカルサーバーで動かす場合の例:

```bash
python3 -m http.server 8765
```

その後 http://localhost:8765/ を開いてください。

## ファイル構成

```
index.html        画面構造
css/style.css     スタイル
js/core.js        共通設定とユーティリティ
js/audio.js       効果音
js/renderer.js    Canvas 描画とテクスチャ
js/game.js        ゲーム状態・ルール・入力・ループ
```
